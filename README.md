# The World Today — Saturday, 21 November 2026

A deterministic, stdlib-only Python program that draws a newspaper front page for 21 November 2026. The broadsheet carries the masthead "THE WORLD TODAY", the date "SATURDAY, 21 NOVEMBER 2026", a world map with 10 markers, three text columns, a market ticker, and 11 news stories from 21 November 2026 — all rendered from code, with no external assets or dependencies.

Entry for the make.fun bounty: https://make.fun/bounty/news-image-20261121

## How to run

```sh
python3 main.py
```

This writes `entry.png` (1024x1024) to `MAKEFUN_OUTPUT_DIR`. No third-party packages are needed — Python's standard library only.
